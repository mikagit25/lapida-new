# Lapida Token Investor & Buyer Structure

## 1. Классификация участников

- **Инвесторы** — все, кто покупает токены на этапе сбора средств (Seed, Private Sale, Public Sale, Launchpad).  
  - Получают токены по специальной цене.
  - Могут иметь бонусы, условия вестинга, права на участие в управлении.
- **Покупатели токена** — все, кто приобретает токены на этапе публичной продажи или после листинга на бирже/DEX.  
  - На старте проекта — также считаются инвесторами.
  - После листинга — могут быть пользователями, трейдерами, держателями.

---

## 2. Категории для распределения

| Категория           | Описание                              | Примечания                    |
|---------------------|---------------------------------------|-------------------------------|
| Seed Investors      | Ранние инвесторы, private sale        | Вестинг, бонусная цена        |
| Public Investors    | Покупатели на launchpad/IDO/ICO       | Цена выше, чем у Seed         |
| Team/Founders       | Создатели проекта                     | Вестинг, блокировка           |
| Advisors           | Консультанты                          | Вестинг                       |
| Community          | Пользователи платформы, активисты     | Награды, конкурсы             |
| Reserve/DAO        | Резервный фонд, управление            | Для дальнейших инвестиций     |
| Marketing/PR       | Маркетинговые расходы                  | Для продвижения               |

---

## 3. Пример распределения токенов (MLPD/GLPD)

| Категория         | Доля (%) | Вестинг/Бонусы        |
|-------------------|----------|-----------------------|
| Seed Investors    | 10       | 12–24 мес, бонус      |
| Public Investors  | 15       | -                     |
| Team/Founders     | 20       | 24–36 мес             |
| Advisors          | 5        | 12 мес                |
| Community         | 20       | -                     |
| Reserve/DAO       | 20       | -                     |
| Marketing/PR      | 10       | -                     |

---

## 4. Принципы учёта инвесторов

- **Каждый покупатель токена на этапе IDO/ICO/Launchpad — инвестор.**
- Инвесторы учитываются по адресам кошельков (EOA), либо через launchpad или sale-контракт.
- Для Seed/Private Sale — собирается whitelist, адреса и условия вестинга.
- Для Public Sale — адреса фиксируются смарт-контрактом или платформой.
- После продажи — инвесторы могут участвовать в голосованиях, получать награды, использовать токен.

---

## 5. Схема процесса

```
[Seed/Private Sale]
   |
[Whitelist -> Покупка -> Вестинг]
   |
[Public Sale / Launchpad]
   |
[Покупка -> Получение токена]
   |
[Листинг на бирже/DEX]
   |
[Пользователи, трейдеры, держатели]
```

---

## 6. Документация для инвесторов

- Публично публикуется структура распределения, условия вестинга, права инвесторов.
- Все адреса инвесторов, команды, резервов фиксируются и доступны для аудита.
- Роли инвесторов и покупателей токена прописываются в whitepaper и на сайте проекта.
