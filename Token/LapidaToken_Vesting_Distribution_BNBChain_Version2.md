# Lapida Token — Vesting & Distribution Scheme (BNB Chain)

---

## 1. Механизм вестинга

**Вестинг** — это механизм блокировки токенов для команды, инвесторов, адвайзеров, чтобы предотвратить мгновенную продажу и обеспечить долгосрочную мотивацию.

### Категории с вестингом:
- **Команда / Founders**
- **Advisors**
- **Seed / Private Sale инвесторы**

### Стандартная схема:

| Категория          | Общая доля (%) | Вестинг-условия                | Тип разблокировки        |
|--------------------|----------------|--------------------------------|--------------------------|
| Команда            | 20             | 12 мес. блокировка, затем линейно за 24 мес. | Linear Vesting           |
| Advisors           | 5              | 6 мес. блокировка, затем линейно за 12 мес.  | Linear Vesting           |
| Seed Investors     | 10             | 10% сразу, 90% линейно за 12 мес.            | Cliff + Linear Vesting   |
| Private Sale       | 10             | 20% сразу, 80% линейно за 12 мес.            | Cliff + Linear Vesting   |
| Public Sale        | 15             | Без вестинга                                 | Нет                     |
| Community/Reserve  | 25             | Без вестинга                                 | Нет                     |
| Marketing/PR       | 15             | Без вестинга                                 | Нет                     |

*Примечание: параметры могут корректироваться под задачи проекта — сроки, проценты и категории.*

## 3. Пример логики смарт-контракта вестинга

**Linear vesting:**  
- Токены блокируются на контракте.
- Разблокировка происходит равномерно каждый блок/день/месяц после периода блокировки (cliff).

**Cliff + Linear vesting:**  
- Часть токенов (например, 10%) становится доступна сразу.
- Остальные разблокируются постепенно по расписанию.

**Основные параметры для контракта:**
- beneficiary (адрес получателя)
- totalAmount (всего токенов)
- cliff (время полной блокировки)
- duration (срок линейной разблокировки)
- start (дата начала вестинга)
- released (сколько уже разблокировано)

- Код смарт-контрактов вестинга будет открыт и доступен для аудита.
