# Техническое задание: Экосистема токенов Lapida

## 1. Lapida Stablecoin (LPD)
- Тип: ERC-20
- Назначение: платежи, эскроу, стабилизация стоимости
- Функции:
  - Mint при депозите резерва
  - Burn при обратном обмене
  - Резервный контракт с возможностью инвестирования части активов
  - Прозрачность резервов
  - Эскроу-блокировка
  - Интеграция с ораклами цен

## 2. Meta Lapida DeFi Token (MLPD)
- Тип: ERC-20
- Назначение: внутренняя валюта, фарминг, стейкинг, награды
- Функции:
  - Mint пропорционально активности пользователей и ликвидности
  - Burn для DeFi-операций
  - Стейкинг/фарминг
  - Рыночная цена, обмен через AMM
  - Оплата внутри платформы
  - Управление эмиссией через GLPD

## 3. Government Lapida Governance Token (GLPD)
- Тип: ERC-20
- Назначение: управление, право эмиссии, голосование
- Функции:
  - Ограниченная эмиссия
  - Голосование (DAO)
  - Минтинг/выпуск MLPD
  - Получение части дохода от резервных инвестиций
  - Вестинг для команды/инвесторов
  - Delegation, спец. управленческие программы

## Общие требования
- Прозрачность и аудит всех контрактов
- Возможность распределения токенов по категориям: инвесторы, команда, пользователи, резерв
- Вестинг для долгосрочных участников
- Интеграция со сторонними сервисами (DeFi, биржи, банки)
- Документация и открытый исходный код
