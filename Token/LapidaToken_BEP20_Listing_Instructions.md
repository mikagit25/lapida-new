# Инструкция по листингу токена Lapida (BEP-20) на платформах BNB Chain

---

## 1. Листинг на PancakeSwap
### 1.1. Добавление токена
- Перейдите на https://pancakeswap.finance/
- Подключите кошелёк (MetaMask, TrustWallet и др.)
- В разделе "Trade" → "Swap" нажмите "Select a token"
- Вставьте адрес вашего токена (BEP-20)
- Проверьте имя, символ, decimals
- Добавьте токен в список

### 1.2. Создание пула ликвидности
- Перейдите в раздел "Liquidity"
- Нажмите "Add Liquidity"
- Выберите ваш токен и базовый токен (BNB, USDT и др.)
- Введите сумму и подтвердите транзакцию
- После создания пула ваш токен будет доступен для обмена

---

## 2. Листинг на TofuNFT
- Перейдите на https://tofunft.com/
- Подключите кошелёк
- В разделе "Create" выберите тип токена (ERC-721/1155 для NFT, BEP-20 для utility)
- Вставьте адрес токена
- Следуйте инструкциям платформы для добавления токена и создания коллекции

---

## 3. Листинг на других платформах (DEX, агрегаторы)
- Найдите раздел "Add Token" или "Submit Token" на выбранной платформе
- Вставьте адрес токена, символ, decimals, описание
- При необходимости заполните форму листинга (контакты, сайт, whitepaper)
- Подтвердите владение токеном (через подпись или транзакцию)

---

## 4. Добавление токена в кошелёк
- В MetaMask: "Import Tokens" → вставьте адрес, символ, decimals
- В TrustWallet: "Add Custom Token" → вставьте адрес, выберите сеть BSC
