# Lapida Token — Technical Architecture & Integration (BNB Chain)

---

## 1. Общая схема архитектуры

Lapida Token экосистема построена на смарт-контрактах BNB Chain, интеграции с DeFi, DAO и внешними сервисами.  
Основные компоненты:

- **Токены:** LPD (Stablecoin), MLPD (Utility/DeFi), GLPD (Governance)
- **Вестинг-контракты:** Для команды, инвесторов, адвайзеров
- **DAO-контракт:** Управление через GLPD, голосование, proposals
- **Sale-контракт:** PinkSale или собственный, для IDO/Pre-sale
- **Multisig-адреса:** Для управления резервами, критическими функциями
- **Резервный контракт:** Хранение обеспечивающих активов LPD
- **DEX-интеграция:** PancakeSwap для листинга, создания пула ликвидности
- **Интерфейс:** Веб-сайт, личный кабинет, дашборд инвестора
- **API:** Для B2B и мобильных приложений

## 3. Описание компонентов

### 3.1. Смарт-контракты токенов

- **LPD:** Stablecoin, обеспечивает платежи и эскроу, динамическая эмиссия через ReserveContract (mint/burn).
- **MLPD:** Utility/DeFi, фиксированная эмиссия, награды, фарминг, стейкинг, регулируется через DAO.
- **GLPD:** Governance, ограниченная эмиссия, права голосования, делегирование.

### 3.2. Вестинг-контракты

- Логика блокировки и линейной/клиффовой разблокировки токенов для разных категорий.
- Контракты независимы от токена, взаимодействуют через функции release(), vest(), etc.
- Публичные адреса и параметры доступны для проверки.

### 3.3. DAO-контракт

- Governor.sol, Timelock.sol, ProposalFactory.sol
- Голосование через GLPD, автоматическое исполнение решений после кворума и timelock.
- Делегирование голосов, публичность решений.

### 3.4. Sale-контракт

- PinkSale — стандартный контракт для IDO, автоматическое распределение, лимиты.
- Возможна интеграция собственного sale-контракта для whitelist/Private Sale.

### 3.5. Multisig и резервный контракт

- Multisig-адреса (Safe) для управления mint/burn, резервом, критическими функциями.
- Резервный контракт хранит USDT/USDC/BNB для обеспечения LPD.

### 3.6. DEX-интеграция

- Листинг и создание пулов ликвидности (LPD/BNB, MLPD/LPD) на PancakeSwap.
- Возможность автоматического добавления ликвидности через контракт.

### 3.7. Интерфейс и API

- Веб-платформа: личные кабинеты, мониторинг балансов, инвестиций, голосований.
- API для интеграции с внешними сервисами (ритуальные компании, архивы, мобильные приложения).
- Отдельный REST/GraphQL API для B2B и партнеров.

## 4. Взаимодействие с внешними платформами

- **PinkSale:** интеграция через стандартные sale-контракты
- **PancakeSwap:** взаимодействие с DEX, создание и управление пулами ликвидности
- **NFT-маркетплейсы:** выпуск мемориальных NFT, интеграция с токенами
- **Мосты/Bridges:** возможность кроссчейн-трансфера LPD/MLPD/GLPD
- **Мобильное приложение:** взаимодействие с API платформы, управление токенами и голосованием
