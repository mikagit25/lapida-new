# Lapida Token Specification (BNB Chain)

---

## 1. Общая информация

**Сеть:** BNB Smart Chain (BEP-20)  
**Стартовая сеть для запуска токенов, IDO и листинга.  
Выбрана за низкие комиссии, популярность среди DeFi-проектов и поддержку крупных launchpad-платформ.**

---

## 2. Токены проекта

### 2.1. LPD — Lapida Stablecoin

- **Тикер:** LPD
- **Стандарт:** BEP-20
- **Адрес:** Будет присвоен после деплоя
- **Назначение:** Стабильный платёжный токен, обеспеченный резервом (USDT, USDC, BNB и др.)
- **Эмиссия:** Динамическая, токены выпускаются при депонировании резервных активов, сжигаются при обратном обмене
- **Функции:**  
  - Платежи внутри платформы Lapida
  - Эскроу и блокировка для обеспечения сделок
  - Использование в DeFi-интеграциях
- **Управление:**  
  - Mint/burn только через ReserveContract
  - Owner — мультисиг-адрес команды

---

### 2.2. MLPD — Meta Lapida DeFi Token

- **Тикер:** MLPD
- **Стандарт:** BEP-20
- **Адрес:** Будет присвоен после деплоя
- **Назначение:** Utility/DeFi токен для наград, фарминга, стейкинга, оплаты сервисов
- **Эмиссия:**  
  - Фиксированная (пример: 10 000 000 MLPD)
  - Mint по событиям: фарминг, стейкинг, решения DAO
  - Burn за использование в DeFi-операциях
- **Функции:**  
  - Стимулирование активности пользователей
  - Раздача наград за действия в платформе
  - Торговля на DEX (PancakeSwap), фарминг/стейкинг
- **Управление:**  
  - Mint/burn регулируется голосованием держателей GLPD (через Governor.sol)
  - Owner — мультисиг-адрес команды

---

### 2.3. GLPD — Government Lapida Governance Token

- **Тикер:** GLPD
- **Стандарт:** BEP-20
- **Адрес:** Будет присвоен после деплоя
- **Назначение:** Governance токен для принятия решений, управления эмиссией MLPD, инвестициями и развитием платформы
- **Эмиссия:**  
  - Ограниченная (пример: 1 000 000 GLPD)
  - Mint при создании, без дальнейшей эмиссии
  - Вестинг для команды и инвесторов
- **Функции:**  
  - Голосование по развитию экосистемы, инвестициям, правилам выпуска MLPD
  - Делегирование прав голоса
  - Получение части дохода от деятельности резервного фонда
- **Управление:**  
  - DAO-контракт (Governor.sol)
  - Вестинг-адреса для команды/адвайзеров
  - Owner — мультисиг-адрес DAO

## 4. Применение токенов в BNB Chain

- **Торговля:**  
  - Листинг на PancakeSwap (DEX) сразу после IDO/launchpad
  - Создание пула ликвидности для MLPD/LPD
- **Продажа:**  
  - Запуск IDO/Pre-sale на PinkSale (BNB Chain)
  - Продажа через собственный сайт для whitelist-инвесторов
- **DeFi-интеграция:**  
  - Фарминг/стейкинг с помощью стандартных смарт-контрактов на BNB Chain
  - Возможность кроссчейн-бриджа для расширения в другие сети
- **Управление:**  
  - Голосование через DAO-контракт, управление параметрами выпуска, резервом, интеграциями

## 5. Пример адресов и взаимодействия

| Категория         | Тип адреса        | Пример использования                  |
|-------------------|-------------------|---------------------------------------|
| Контракт токена   | BEP-20            | 0x...LPD, 0x...MLPD, 0x...GLPD        |
| Owner             | Multisig (Safe)   | Управление mint/burn                  |
| Reserve           | Smart Contract    | Хранение обеспечивающих активов       |
| Фарминг/стейкинг  | Smart Contract    | Награды, блокировки                   |
| DAO/голосование   | Smart Contract    | Управление проектом                   |
| Вестинг           | Smart Contract    | Блокировка для команды/адвайзеров     |
