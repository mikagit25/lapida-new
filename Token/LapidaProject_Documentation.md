# Документация проекта Lapida (Draft)

---

## 1. Описание проекта

**Lapida** — это инновационная блокчейн-экосистема, предназначенная для цифровых мемориалов, хранения, передачи и управления памятью о важных событиях и людях.  
В основе платформы лежит набор смарт-контрактов и токенов, обеспечивающий прозрачность, безопасность, децентрализацию и новые возможности для B2C/B2B сервисов, связанных с памятью, наследием и цифровой идентичностью.

---

## 2. Миссия и цель

- **Миссия:** Создать цифровое пространство, где память о людях и событиях будет защищена, управляема и передаваема с помощью современных технологий.
- **Цель:** Обеспечить каждому пользователю возможность безопасно создавать, хранить и передавать цифровые мемориалы, используя инструменты блокчейна, DeFi и DAO.

---

## 3. Ключевые компоненты платформы

- **Токены:**
  - LPD (Lapida Stablecoin) — платёжный и расчётный токен, обеспеченный резервом.
  - MLPD (Meta Lapida DeFi Token) — utility/DeFi токен для наград, фарминга, стейкинга, оплаты сервисов.
  - GLPD (Government Lapida Governance Token) — governance токен для управления, голосования и принятия решений.
- **Смарт-контракты:** Эмиссия, распределение, стейкинг, эскроу, резерв, DAO.
- **Платформенные сервисы:** Виртуальные мемориалы, marketplace, интеграция с внешними DeFi сервисами, API для B2B.
- **Интерфейсы:** Веб-платформа, мобильное приложение, launchpad для токенсейлов.

---

## 4. Токеномика

### 4.1. Типы токенов и их функции
- **LPD:** расчетная единица, стабильная стоимость, используется в оплате услуг, хранится в резерве.
- **MLPD:** внутренняя валюта, награды, стейкинг/фарминг, поддержка внутреннего рынка сервисов.
- **GLPD:** право управления проектом, участие в голосованиях, регулирование эмиссии MLPD, принятие ключевых решений.

### 4.2. Механика эмиссии и сжигания
- **LPD:** выпуск под резерв, сжигание при выводе.
- **MLPD:** выпуск по активности, фармингу, решениям DAO, сжигание за DeFi-операции.
- **GLPD:** ограниченная эмиссия, распределение по категориям, вестинг.

## 6. Архитектура смарт-контрактов

- **LPDToken.sol** — ERC20, mint/burn через ReserveContract.
- **ReserveContract.sol** — хранит обеспечивающие активы, инвестирует часть средств.
- **MLPDToken.sol** — ERC20, mint/burn под управлением GLPD (DAO).
- **Staking/Farming.sol** — награды за активность, блокировка MLPD.
- **GLPDToken.sol** — ERC20, ограниченная эмиссия, голосование.
- **Governor.sol** — DAO, управление проектом, решения по выпуску MLPD, инвестициям.
- **Vesting.sol** — вестинг для команды и адвайзеров.
- **SaleContract.sol** — продажа токенов инвесторам.
- **EscrowContract.sol** — блокировка платежей.
- **Oracle.sol** — получение рыночных цен для стабильности.

---

## 7. Процесс инвестирования и покупки токенов

- **Seed/Private Sale:** Сбор whitelist, распределение через sale-контракт, условия вестинга.
- **Public Sale/Launchpad:** Массовая продажа, фиксируется смарт-контрактом или платформой (PinkSale, PancakeSwap и др.).
- **Листинг на DEX:** Доступность токена для торговли, создание пула ликвидности.
- **Вестинг:** Встроенные механизмы блокировки для команды и ранних инвесторов.
