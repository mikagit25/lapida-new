# Техническое задание: AI-психолог-консультант для поддержки при утрате

## 1. Архитектура и компоненты

### 1.1. Фронтенд (React)
- Страница/раздел “AI-психолог” (`/psychologist`).
- UI: чат-интерфейс (текст/голос), история сессии, кнопка “новая сессия”, переключатель языка, “экстренная помощь”.
- Голосовой ввод: Web Speech API (SpeechRecognition) или сторонний сервис.
- Голосовой вывод: Web Speech API (SpeechSynthesis) или облачный TTS (Google, Yandex, Azure).
- Авторизация (для платных функций и истории).

### 1.2. Бэкенд (Node.js/Express)
- API общения с AI (OpenAI, YandexGPT, Azure и др.).
- API хранения/загрузки истории сессий (MongoDB).
- API управления подпиской/оплатой (Stripe, ЮKassa, PayPal и др.).
- API лимитов (бесплатные/платные пользователи).
- (Опционально) API аналитики и обратной связи.

# Подробный пошаговый план реализации

## Этап 1. MVP (текстовый AI-психолог)
1. Создать новую страницу `/psychologist` в клиенте (React):
   - Разметка: чат-интерфейс, поле ввода, кнопка отправки, область истории сообщений.
   - Добавить предупреждение о не-медицинском характере сервиса.
2. Реализовать хранение истории сообщений в состоянии компонента (frontend).
3. Настроить API-роут на сервере `/api/psychologist/chat`:
   - Принимать сообщения пользователя, отправлять их к AI (OpenAI, YandexGPT и др.), возвращать ответ.
   - Ограничить количество сообщений для анонимных пользователей (например, 10).
4. Интегрировать frontend с backend: отправка сообщений, отображение ответов.
5. Добавить обработку ошибок (нет ответа, лимит превышен и т.д.).
6. (Опционально) Добавить временное хранение истории сессии (localStorage).

## Этап 2. Голосовой ввод/вывод (бесплатный режим)
1. Добавить кнопку "Говорить" для голосового ввода (Web Speech API):
   - При нажатии — распознавание речи, результат вставляется в поле ввода.
   - Обработка ошибок и поддержка браузеров.
2. Добавить кнопку "Слушать" для голосового вывода (Web Speech Synthesis API):
   - Ответ AI озвучивается голосом браузера.
   - Возможность остановить/повторить озвучку.
3. UI: визуальная индикация записи и воспроизведения.

## Этап 3. Авторизация и платная версия
1. Реализовать регистрацию/вход (если не реализовано).
2. Интегрировать платёжную систему (Stripe, ЮKassa, PayPal):
   - Создать страницу оплаты/подписки.
   - Проверять статус подписки при обращении к AI.
3. Для платных пользователей:
   - Снять лимиты на сообщения и длительность сессии.
   - Сохранять историю всех сессий в MongoDB (привязка к пользователю).
   - Реализовать личный кабинет: просмотр истории, настройки.
4. Для бесплатных — оставить ограничения и временное хранение.

## Этап 4. Голосовой вывод через облачные TTS (платный режим)
1. Зарегистрировать облачный TTS (Google, Yandex, Azure) и получить API-ключи.
2. Реализовать backend-роут `/api/psychologist/tts`:
   - Принимать текст, возвращать аудиофайл/ссылку.
3. На фронте для платных пользователей:
   - Воспроизводить аудио-ответ через HTML5 audio.
   - Добавить выбор голоса/тона (если поддерживается).

## Этап 5. Дополнительные функции
1. Переключение языков:
   - Добавить выпадающий список языков, хранить выбор в состоянии/профиле.
   - Передавать выбранный язык в AI и TTS.
2. Кнопка “экстренная помощь”:
   - Открывает окно с телефонами горячих линий, советами, ссылками.
3. Аналитика и обратная связь:
   - Собирать обезличенную статистику использования.
   - Форма обратной связи для отзывов и жалоб.
4. Улучшение UX:
   - Анимации, автофокус, мобильная адаптация, accessibility.

## Этап 6. Безопасность и этика
1. Явное предупреждение о не-медицинском характере.
2. Анонимность: не хранить личные данные без согласия.
3. Возможность удалить историю сессий.
4. Модерация опасных запросов:
   - Фильтрация/алерт при тревожных сообщениях, вывод контактов горячей линии.
